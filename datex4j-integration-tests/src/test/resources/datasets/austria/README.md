# Dataset: austria

**No data file is committed in this directory yet.** See
[`../README.md`](../README.md) for why (licence/size policy) and how to contribute one.

## How to obtain a real dataset

No dataset confirmed as a DATEX II AFIR recharging publication was found for Austria at the time of
writing:

- The closest catalogue entry is "ÖAMTC E-Ladestationen" on Mobilitätsdaten Österreich
  (<https://mobilitaetsdaten.gv.at/en/data?filter=940>), but it is published as **JSON via an
  OAuth2-authenticated REST API**, not DATEX II, and its licence is not stated in the catalogue
  listing.
- The platform's general downloads page (<https://mobilitaetsdaten.gv.at/en/downloads>) indicates
  Austria's standard open-data licence is typically Creative Commons (CC-BY), but this was not
  confirmed specifically for a charging dataset.

See
[`../../../../../../docs/afir/nap/austria.md`](../../../../../../docs/afir/nap/austria.md) for the
full picture. This README will be updated with concrete download instructions once a DATEX II
dataset is confirmed — no URL or format is guessed here in the meantime.
