# Dataset: denmark

**No data file is committed in this directory yet.** See
[`../README.md`](../README.md) for why (licence/size policy) and how to contribute one.

## How to obtain a real dataset

No public, directly downloadable AFIR/DATEX II dataset for Denmark could be confirmed at the time of
writing:

- The Danish Road Directorate's (Vejdirektoratet) data-exchange platform,
  <https://du-portal-ui.dataudveksler.app.vd.dk>, requires requesting login credentials before any
  data can be accessed — there is no public, unauthenticated download.
- The Danish Agency for Climate Data (Klimadatastyrelsen) describes a **planned** national
  charging-point data overview (see
  <https://www.eng.klimadatastyrelsen.dk/green-transition-and-climate-adaptation/national-mapping-of-charging-point-data>),
  not yet a live, citable dataset.

See
[`../../../../../../docs/afir/nap/denmark.md`](../../../../../../docs/afir/nap/denmark.md) for the
full picture. This README will be updated with concrete download instructions (source URL, licence,
format) once a public dataset is confirmed — no URL or format is guessed here in the meantime.
